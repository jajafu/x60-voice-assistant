# 審查變更

先讀 `AGENTS.md`、任務計畫、要審查的差異（未提交變更、最後一次提交或指定 commit）與測試紀錄。核對驗收紀錄所記的 commit 與產物識別是否對應要審的內容，並檢查 Android APK SHA-256、產品版本與建置號；適用時核對 MuMu／測試手機結果。不一致時將該結果標為失效或未驗證。此專案沒有 Preview／部署 revision。

優先找出可重現的錯誤、範圍偏離、相容性與安全風險；未執行的測試標為未驗證。每項發現寫出檔案位置、觸發條件、影響與建議，區分必須修正與可選改善。若使用另一個模型／子 Agent，記錄實際使用情況；同一模型重看不稱為獨立審查。只回報結論，不編輯程式；已推送的內容要修就開新的修正任務，不改寫已推送歷史。最後由使用者本人決定。
