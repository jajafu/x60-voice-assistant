# 一人開發與 AI 分工

只有你一位人類開發者。一般任務用一個主要 AI Agent 即可；需求不清或高風險時再增加子 Agent 或換模型複查。這些 AI 角色不代表多位共同實作者，也不取代你的核准決定。

| 工作 | 建議模型 | 使用時機 |
|---|---|---|
| 整理資料、找檔案、排版 | 快速／免費 | 結論可從原文直接核對。 |
| 一般任務分析與實作 | 標準能力 | 範圍清楚、可測試。 |
| 架構、難重現 Bug、資料與安全風險、變更複查 | 較高能力 | 判斷錯誤的代價較高。 |

OpenCode 提供可選的 `task-analyst` 與 `change-reviewer` 子 Agent；它們不自動啟動，也沒有綁定模型。若只用同一個模型重看一次，要如實記錄，不稱為獨立模型審查。多模型設定與 Codex 入口見 `docs/OPENCODE_OPENCHAMBER.md`。
