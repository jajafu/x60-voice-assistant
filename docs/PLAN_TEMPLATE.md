# 任務計畫範本

小型變更在對話中確認做法即可，不需要計畫檔。變更較大、跨多個檔案或有風險時，把下面內容貼在對話中，或存成 `work_plans/<主題>.md`（本專案預設納入 Git）。尖括號是**每次任務當下填寫**，不是專案參數。

```markdown
## 計畫：<任務主題>

- 目標與範圍：<要完成什麼；本次不做什麼>
- 做法：<預計修改哪些部分>
- 驗收：<完成後如何判斷正確；以完整 commit 與 APK SHA-256 識別受測內容，適用時含 MuMu／`docs/testing.md` 真機項目>
- 測試：<要執行的命令或人工步驟>
- 產品版本：<需更新／不需更新／待決；依 `docs/DEVELOPMENT.md` 說明原因與預計修改的 `versionName`／`versionCode`，以及 Android APK／MuMu smoke 是否適用>
- 風險／回退：<主要風險與恢復方式；沒有寫「無」>
- 待決問題：<需要我決定的事；沒有寫「無」>
```

使用者在對話或計畫檔明確同意按此範圍實作，才算核准。AI 記錄核准來源；若後續大幅改變範圍，重新向使用者確認。
